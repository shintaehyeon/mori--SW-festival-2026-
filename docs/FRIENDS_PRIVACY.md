# 친구 연결·공개 범위·짧은 메시지
기준: 2026-10-28 KST

- 기본 비공개. 공개를 선택하면 로그인한 이용자에게 모리 닉네임·아바타·90초 내 접속을 표시하며 초대를 받을 수 있다.
- 별도 컨디션 공유 스위치를 켜야 수락한 친구에게 직접 입력한 컨디션/한마디/작성시각을 제공한다. 건강일지·복용약·워치 측정치·주소·실시간 위치는 공유 대상이 아니다.
- 비공개로 바꾸면 타인 발견 목록에서 제외하고 친구에게도 접속 여부/컨디션을 반환하지 않는다. 기존 친구 연결과 메시지는 유지된다.
- 표시 상태는 현재 측정·진단이 아닌 사용자가 작성한 상태. 기록시각과 최근 접속은 구분한다. 데이터 통신 실패 시 이전 상태를 현재 상태로 표시하지 않고 목록을 비운다.
- 공개 접속자에게 앱 안에서 초대장 보내기 → 받은 사람이 수락/거절. 초대 코드 방식도 지원: 128비트 임의 코드, 서버 해시 저장, 7일 유효, 한 번 수락 가능, 새 코드 생성 시 이전 코드 취소. 코드를 전달받은 사람이 수락하므로 신뢰하는 사람에게만 전달한다.
- 친구끼리만 20자 이내 1줄 응원 메시지. 클라이언트 characters 및 서버 Intl.Segmenter로 한글·이모지 grapheme 단위 길이 검사. 친구 외 송신 거절, 사용자당 시간당 30건 제한.
- 친구 연결 해제/차단 시 두 사람의 연결과 저장된 쌍방 메시지 삭제. 차단 시 재초대/코드 수락/서로의 발견 목록 접근 제한. 현재 차단 해제 화면은 미구현.
- 계정 탈퇴 시 FK cascade로 관련 친구/초대/메시지/설정 삭제. 별도 자동 메시지 보존기한은 아직 없고 연결 해제/차단/탈퇴 전까지 저장한다. 운영 배포 전 최종 처리방침에 반영해야 한다.
- 설정/연결/메시지는 SQLite에 지속 저장, 접속만 서버 메모리 기반. 화면은 30초 갱신, 서버나 워치 기반 실시간 감시·푸시 알림 아님.
- 다른 학생·후기를 가상으로 채우지 않는다. 로컬 서버의 접속 목록이 실제 캠퍼스 이용실적을 의미하지 않는다.
