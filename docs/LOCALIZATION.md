# 6개 언어 구현 및 인수인계 — 2026-11-06

## 구현
- 한국어(ko), 중국어 간체(zh), 일본어(ja), 베트남어(vi), 영어(en), 프랑스어(fr).
- `app/lib/localization.dart`, `app/assets/i18n/catalog.json`: 509개 메시지 키. 첫 실행은 기기 언어, 미지원 언어는 영어. 선택한 언어는 기기 보안 저장소에 보관.
- 상단 메뉴에서 전환. 화면 입력값과 병원 필터를 유지한다. 사용자 작성 내용, 주소, 병원 공식 명칭은 자동 번역하지 않는다.
- 병원 공식 한국어 이름을 크게 유지하고 작은 글씨로 로마자 읽기와 현지화한 기관 종류를 표시한다. 예: 군산병원 → Gunsan · Hôpital / Gunsan Byeongwon.
- 읽기는 음절 기반 참고 표기다. 공식 외국어 상호, IPA, 일본어 가타카나/중국어 발음 표기, 완전한 한국어 음운 변환이 아니다. 고유명사와 실제 발음은 별도 검수가 필요하다.
- 병원 검색은 받은 공개 스냅샷을 대상으로 한국어·로마자·6개 언어 진료과를 찾는다. 언어 변경 때문에 서버 필터가 결과를 미리 제외하지 않도록 클라이언트에서 검색한다.
- 커뮤니티 언어 값도 6개 언어와 Other 지원. 기존 게시물 원문은 그대로 보존한다.
- PDF 제목/항목은 한국 의료진을 위한 한국어·영어 유지. 6개 언어 입력문 보존을 위해 Noto Sans, NanumGothic, Noto Sans CJK 글꼴을 번들링한다. UI 언어 선택 자체가 건강정보를 AI로 보내지 않는다.

## 검증 근거와 한계
- Flutter 32개 테스트: 카탈로그 6개 언어 누락, 기존 문자열 연결, 390×844 방문 준비 입력/언어 전환 유지, 병원 검색·이름, 6개 언어 PDF 및 원본 스냅샷 보존 포함.
- 서버 23개 테스트: 6개 언어 커뮤니티 작성/필터와 Unicode 보존 포함.
- iPhone 16e 시뮬레이터: 베트남어→일본어→중국어 간체→프랑스어 병원 화면, 한국어 이름, 현지화된 유형, 선택한 이비인후과 필터 유지 확인. 증거는 docs/screenshots/qa-20261106-*.
- PDF 가상 사례의 중국어·일본어·베트남어·프랑스어와 37.2 수치 추출/시각 확인. 원어민 번역 감수, 실제 의료진 평가, 실제 AI 번역 품질은 미검증이다.
- 시스템 권한창은 OS 설정 영향을 받는다. 글꼴 추가로 배포 용량이 늘었으며 CJK 파일은 약 21MB다.
- UI 지원을 ‘완벽한 의료 번역’으로 발표하지 않는다. 실제 기기/외부 접속/실제 AI 검증은 기존 인수인계의 별도 완료 조건을 따른다.

- 최종 정적 분석 통과, iOS simulator/web 빌드 성공. 앱 재시작 후 프랑스어 선택 유지 확인. 짧은 프랑스어 하단 메뉴 배치 확인: qa-20261106-fr-menu-final.png. 기존 예제 PDF는 유지했으며 다국어 가상 사례 PDF는 테스트에서 별도 생성·검증했다.

## 다음 작업
1. 원어민별 화면 문구와 긴 입력 검수. 번역 키의 6개 값은 함께 갱신한다.
2. 기관 제공 공식 외국어 상호가 확보되면 출처와 함께 자동 읽기보다 우선한다.
3. 증상·복약·알레르기 원문과 숫자는 UI 번역 과정에서 수정하지 않는다.
