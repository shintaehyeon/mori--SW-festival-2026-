### 소속·지역 집계 확장
한동대 전용 설정을 대체하여 소속 유형(학교/직장/기타), 기관명, 활동 지역, 집계 참여 여부를 계정에 저장한다. 기관명/지역명은 Unicode NFKC·공백 제거·소문자화로 비교하며 번역·약칭·유사 기관명 자동 통합은 하지 않는다. 기관 그룹은 유형+기관명, 지역 그룹은 입력 지역명으로 별도 집계한다. 같은 소속이 다른 지역에 있으면 소속 수에는 함께, 지역 수에는 별도로 집계한다. 소속/지역 변경은 활성 계정의 다음 조회에 반영된다. 타 그룹의 명단·이름·건강정보는 반환하지 않는다. 기존 한동 설정은 읽을 때 호환 변환한다.

## 한동대 지원 연락망
EmergencyPage에서 HandongSupport를 비회원에게도 노출한다. 공개 번호/메일을 정적 데이터로 제공하며 출처·조회일을 함께 표시한다. tel/mailto/공식 출처 URL만 외부 앱으로 열고 메일 본문이나 건강정보는 전달하지 않는다. 새로운 서버 저장·학교 전송 기능은 없다. 6개 언어 문구를 추가했다.


### 2026-11-08 제출 전 개선: 결과물을 실제로 꺼내 보여주기
- 최초 의료기관 이용 지원·한국어 요약/번역 영역의 핵심 완성도 개선. 새 제품 범위 추가 없음.
- 진료 준비표 상단에 명시적인 PDF 저장·공유 버튼, 진행 중 중복 클릭 방지, 실패 후 재시도 안내를 추가했다. 실패해도 의료진 표시 화면은 유지한다.
- 웹 PDF는 브라우저 다운로드 경로, 네이티브는 OS 공유 경로를 사용한다. 내보내기 요청과 실제 파일 저장 완료를 구분한다.
- 통신 끊김과 시간 초과를 6개 언어로 안내하고, 저장 중 시간 초과에는 중복 생성을 피하도록 저장된 준비표부터 확인하게 한다. POST 자동 재시도는 하지 않는다.
- 문제의 출발점은 프랑스인 한동대 유학생 팀원 Caroline의 실제 경험(사용자 제공)이다. 신태현은 개발, Caroline은 문제 정의·최종 테스트·영상 발표 담당. 최종 테스트 결과는 아직 보고되지 않았다. 절차: `docs/CAROLINE_FINAL_TEST.md`(문서 폴더에서는 `CAROLINE_FINAL_TEST.md`).


### 2026-11-08 최종: 기본 한 장 준비표
사용자 승인에 따라 최초 건강기록 영역은 유지하되, 준비표 작성 화면의 과거 기록은 기본 접힘 선택 첨부로 옮겼다. 기록 없는 신규 사용자는 첨부 단계가 보이지 않는다. PDF와 의료진 화면은 동일한 전체 원문/번역 데이터를 사용한다. 확인한 한국어 증상·시작 시점을 크게 먼저 표시하고 원문도 같은 문서에 보존한다. 미확인 AI 초안은 원문 뒤에 상태를 표시한다. 부위·통증·체온은 입력했을 때만, 선택한 과거 기록은 별첨으로 표시한다. 빈 메모 페이지와 중복 요약/상세 페이지를 제거했다. 짧은 원문/미확인/확인 완료 사례는 각각 한 장이고 긴 기록은 자동 페이지 확장한다. 의료기관 공식 문진표가 아닌 자체 설계한 환자 작성 방문 준비표다.


## 2026-11-08 병원 카드·게스트 여정 개선
병원명/주소/의사 수/핵심 방문 준비 CTA를 분리하고 상세 진료과는 접었다. Google 외부 길찾기와 전화만 보조 행동으로 남겼다. 게스트로 원문 저장·실제 Gemini 번역·확인 저장·PDF까지 연결했다. 게스트 세션 24시간, 만료 데이터는 다음 요청 시 삭제. 계정 전환 전 PDF 저장 안내. 후기 열람·작성은 계정 로그인 필요; 작성 형식 예시는 실제 후기가 아니다. Google 공식 로그인 플러그인과 서버 토큰 검증을 준비했으나 OAuth 클라이언트 미설정으로 버튼은 숨김. Firebase 미사용, Node.js/SQLite 유지.
