# MORI 기술 설명 — 제출용 사실 기준
기준일: 2026-10-28 KST. 버전은 선언 의존성과 실행 환경을 구분한다. 최종 제출 시 lockfile과 실행 결과를 재확인한다.

## 발표용 요약
모리는 Flutter로 만든 외국인 의료 이용 지원 앱입니다. Node.js 서버와 SQLite로 계정별 건강정보·일상 기록·방문 카드·커뮤니티 글을 관리합니다. 심평원 공개 CSV를 병원 식별키로 결합해 포항 의료기관 669곳의 정보를 연결했습니다. AI는 사용자 입력을 한국어로 정리·번역하는 서버 연동 구조를 구현했지만 현재 실제 모델 연결과 품질 검증은 완료하지 않았습니다.

선언 버전은 app/pubspec.yaml, server/package.json에 근거한다. 실제 고정 버전은 각각 lockfile을 따른다. 최신 런타임 버전은 제출 시 실행해서 기록한다.

## 데이터·실행 흐름
앱 입력 → 서버 인증/입력검증 → 계정별 SQLite 저장 → 사용자가 선택한 기록으로 방문 카드 스냅샷 생성 → (AI 설정 시) 서버 번역·검증 → 사용자 대조·수정·확인 → 의료진에게 카드 표시.

병원 검색은 공식 ZIP → CSV 결합/포항 추출 → server/resources/hospitals.json → GET /api/hospitals → Flutter 검색 화면으로 연결된다. 실시간 지도 API에서 목록을 받아오는 방식은 아니다.

## 데이터 출처와 한계
- 심평원 전국 병의원 및 약국 현황_20260930: https://www.data.go.kr/data/15051059/fileData.do
- 공공누리 제1유형 출처표시. 전국 원본은 reference-data/HIRA_202609.zip, 앱에는 포항 669개 기관만 반영.
- 이름·종별·주소·전화·신고 진료과·전문의 수·일부 병상 수 제공. 의료 질 순위나 현재 빈 병상/진료 가능 여부가 아님.
- Google/Naver/Kakao는 현재 외부 지도 검색 링크. 지도 SDK·후기 API 연동이라고 발표하지 않음.
- 자체 방문 경험은 병원명 정확 일치로 조회. 작성자 국적/실제 방문 인증 없음. 외부 후기 원문 수집 없음.

## 보안·신뢰 범위
- 비밀번호 scrypt 해시, 세션·계정별 소유권 검사, 웹 HttpOnly 쿠키, 네이티브 토큰 저장 구조.
- API 키는 서버 환경변수에만 두도록 설계. .env와 사용자 DB는 출품 소스에서 제외.
- 원문/번역본 구분, 없음/모름 구분, AI 입력 숫자 보존 검사. 이것만으로 임상적 번역 정확도를 입증하지는 않음.
- 현재 SQLite 건강 데이터 자체 암호화·운영 배포 보안·정식 사용자 동의 절차·임상 검증은 미완료.
- 앱은 진단/처방/실시간 응급관제 시스템이 아님. 전화·문자 앱 연결이 통화·전송·수신 완료를 의미하지 않음.

## 한동 커뮤니티 접속 집계
- Flutter 타이머로 30초마다 서버 heartbeat. 앱 비활성/위젯 종료 시 삭제 요청, 강제 종료·연결 실패 시 90초 만료로 제외.
- 본인 선택 소속(한동)만 포함. 계정별 중복 제거, 활성 세션 여부 검사, 로그아웃/탈퇴 세션은 제외. 재학 인증 없음.
- 서버 메모리의 임시 집계이며 단일 서버 범위. 재시작 시 초기화, 여러 서버를 쓰는 운영 환경에서는 공유 저장소 필요.
- 총계만 반환. 다른 이용자 닉네임·건강정보·이메일을 반환하지 않음. 내 아바타 닉네임은 /api/avatar로 저장.
- 로컬 앱은 실제 캠퍼스 전체 접속 현황이 아니며 배포 전 사용자 활성도를 주장하지 않는다.

### 소속·지역 집계 확장
한동대 전용 설정을 대체하여 소속 유형(학교/직장/기타), 기관명, 활동 지역, 집계 참여 여부를 계정에 저장한다. 기관명/지역명은 Unicode NFKC·공백 제거·소문자화로 비교하며 번역·약칭·유사 기관명 자동 통합은 하지 않는다. 기관 그룹은 유형+기관명, 지역 그룹은 입력 지역명으로 별도 집계한다. 같은 소속이 다른 지역에 있으면 소속 수에는 함께, 지역 수에는 별도로 집계한다. 소속/지역 변경은 활성 계정의 다음 조회에 반영된다. 타 그룹의 명단·이름·건강정보는 반환하지 않는다. 기존 한동 설정은 읽을 때 호환 변환한다.
