사용자 요청에 따라 의료기관 이용 지원 핵심 기능으로 위치 기반 탐색을 추가했다. 현재 위치 버튼을 눌렀을 때만 전경 위치 권한을 요청하고 1회 조회한다. 기기 메모리에서 공식 HIRA 좌표와 직선거리를 계산해 전체 검색 결과를 가까운 순으로 정렬한다. 거리 미상 기관은 마지막에 둔다. 위치 정확도·확인시각·포항 한정 데이터·직선거리 안내를 표시한다. 위치 권한 거절·서비스 꺼짐·시간 초과에도 위치 없이 검색 가능. 사용 중단 시 위치를 지우고 진행 중 요청 결과도 무시한다. 백그라운드 추적 없음. 위치를 모리 서버/AI/프로필/친구에 전달하지 않는다.

지도는 사용자 버튼 선택 시 flutter_map/OpenStreetMap 타일로 표시한다. 지도 제공자에게 IP와 표시 지역 타일 요청이 전달됨을 UI에 알린다. 지도에는 최대 50개 병원과 현재 위치, 병원명·거리 팝업 및 외부 길찾기를 제공한다. 외부 길찾기에 현재 GPS 좌표를 명시적으로 넣지 않는다. 거리와 지도는 실시간 진료/응급 수용/도보시간 보장이 아니다. 실제 기기의 GPS/권한 철회/근사 위치 검증은 별도다.


### 위치·지도 검증 결과
서버 21개·앱 13개 테스트 통과, Flutter analyze 문제 없음, iOS 빌드와 웹 빌드 성공. iPhone 17 Pro / iOS 26.2 시뮬레이터에서 전경 위치 권한의 한 번 허용, 가상 위치 읽기, 포항 가상 좌표(36.019,129.343) 기준 지도 타일·현재 위치·병원 마커 표시, 마커 선택→병원명·906m 직선거리·길찾기 버튼 표시를 확인했다. 표시된 거리는 테스트 좌표 기준이며 사용자 실제 위치가 아니다. 실제 기기 GPS·권한 거절/영구 거절/근사 위치 및 Android 실기기 검증은 남아 있다. 지도 기본 공개 OSM 타일은 시제품 검증 용도이며 공개 운영 전에 타일 이용정책과 트래픽에 맞는 공급자를 확인한다.


## 2026-11-03 신체 그림 카테고리·한영 진료과
사용자 요청으로 병원 화면 상단에 직접 작성한 벡터 신체 일러스트 9개(머리/눈/귀코목/치아/장기/뼈관절/피부/골반/전신)를 추가했다. 선택 시 신고 진료과명과 정확히 일치하는 기관으로 필터링한다. 증상 진단이나 응급도 분류가 아니며 선택한 관련 과목을 보여준다. 위치 설정 시 거리순 유지, 지도도 동일 필터 사용. 한국어 내과와 한방내과를 부분 문자열로 혼동하지 않는다.
병원 목록에서 신고 전문의가 있는 진료과 최대 3개를 한영으로 표시하고 펼치면 모든 신고 진료과와 과목별 전문의 수를 한영으로 제공한다. 0명은 전문의 보유로 표시하지 않으며 자료 기준일의 신고 수와 현재 방문 가능 여부를 구분한다. 모든 현재 데이터 진료과에 영문 명칭 대응을 작성했다. 공식 명칭 참고: https://www.snubh.org/dh/module/en_medicaldeptList.do?DP_CD=EN&MENU_ID=001002 ; 탐색 안내 참고: https://global.seoul.go.kr/hmpg/finf/welf/emer/contPageDetail.do?conts_no=4B5A1B2AF5794457AAB3E8721C95C9C9&lang=en .

검증: Flutter analyze 문제 없음, 앱 테스트 16개 통과(전체 진료과 영문 대응·정확한 과목 필터·작은 화면 그림 선택 포함), 웹/iOS 빌드 성공. iPhone 17 Pro 시뮬레이터에서 신체 그림 9개 표시와 장기 선택→내과/가정의학과 신고 기관 228건으로 결과 자동 이동을 확인했다. 신고 과목별 0명과 병원 전체의 다른 전문의도 따로 표시한다. 증거: screenshots/ios-body-categories.png, screenshots/ios-specialties-en.png.

## 2026-11-03 일반의료·한국전통의학·약국 분리
기본 카테고리는 한의원/한방병원을 제외한 일반의료 535곳(치과·보건기관 포함)이다. 한의원128·한방병원6은 한국 전통의학 탭134곳에만 표시한다. 의료 신체 그림 필터는 일반의료에만 적용하며 지도·거리 결과도 선택 카테고리와 일치한다.
원본 ZIP의 약국 CSV에서 포항237곳을 별도 pharmacies.json으로 추출했다. 원본 종별은 모두 약국이며 양약/한약 면허·개설자 구분 필드가 없다. 양약국/한약국 카테고리를 만들되 검증된 classificationEvidence가 있는 기관만 넣는다. 현재237곳은 모두 유형 미확인 별도 카테고리로 제공한다. 상호의 한약 문자열로 분류하지 않는다(편한약국/행복한약국 등 오분류 방지). 이는 한약국이 없다는 뜻이 아니라 구분 근거가 없다는 뜻이다. 정밀 분류는 지자체/공식 확인 근거를 확보한 뒤 추가한다.

검증: 서버22개·앱18개 테스트 통과, 코드 검사와 웹/iOS 빌드 성공. 아이폰 UI에서 Korean medicine 선택 시134건과 전통의학 표기, 유형 미확인 약국 선택 시237건을 확인했다. 양약국/한약국 확인 데이터가 아직 없다는 원본 제약은 남아 있다.
