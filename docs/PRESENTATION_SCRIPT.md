## 촬영 전

- 앱과 서버를 켜고 프랑스어 UI로 설정. 모든 예시는 가상 데이터로만 진행.
- 가상 계정으로 미리 로그인해 두고, 실제 연락처·API 키·메일 화면은 녹화하지 않는다.
- 가상 알레르기 `TEST ONLY: Penicillin allergy`, 복용약 `없음`으로 준비. 사실처럼 사용자 자신의 의료정보를 입력하지 않는다.
- 기관 데이터에 있는 강이비인후과의원을 검색해 방문 준비를 시연한다. 해당 기관의 외국어 진료나 예약을 보장하는 표현은 하지 않는다.
- 과거에 확인 저장한 카드는 재번역이 차단된다. 새 가상 준비표를 만들어 번역을 촬영한다.
- 실제 AI 로딩은 성공 장면까지 기다린다. 편집으로 대기 시간을 줄이면 화면에 ‘대기 구간 단축’ 표시. 튜토리얼을 실번역 영상인 것처럼 사용하지 않는다.
- 첫 화면 119/112는 안내만 촬영하고 실제 전화 버튼을 누르지 않는다.

## 00:55–01:20 · 슬라이드 3·4 · 해결 구조

로그인 없이 일반 진료 경로에서 기관을 탐색할 수 있습니다. 긴급 화면에는 119·112와 별도로 한동대 학생 지원 연락망을 안내합니다. 부위 그림과 진료과 명칭을 보고 병원을 좁혀 갑니다. 데이터는 심평원의 2026년 9월 말 기준 포항 의료기관 669곳이며, 실시간 진료 여부를 뜻하지 않습니다. 위치를 허용하면 직선거리순으로 볼 수 있고, 길찾기는 외부 Google 지도와 연결합니다.

앱 내부 지도가 켜지는 장면은 키 설정·검증 전에는 촬영하지 않는다. 슬라이드 4의 기관 탐색 캡처는 구현 당시 화면이고 실제 시연은 현재 앱으로 보여준다.

## 01:20–02:50 · 실제 앱 녹화 · 핵심 시연 90초

### 01:20–01:35 기관 선택
화면: 귀·코·목 카테고리 또는 병원 검색 → 강이비인후과의원 상세 → 방문 준비.

나레이션: 프랑스어를 사용하는 학생이 이틀 동안 목이 아픈 가상 상황입니다. 관련 진료과와 기관 정보를 확인하고 방문할 병원을 선택합니다. 이 과정은 AI 진단이나 자동 진료과 판정이 아닙니다.

### 01:35–01:55 프랑스어 입력
화면에 입력할 문장:
`EXEMPLE FICTIF : J’ai mal à la gorge depuis deux jours.`
시작 시점: `Depuis deux jours.`

나레이션: 내 언어로 증상과 시작 시점을 적습니다. 알레르기와 복용약도 확인하고, 상세 내용은 선택이며, 과거 건강기록이 없어도 바로 만들 수 있습니다. 기록이 있다면 접힌 선택 첨부에서 고릅니다. 여기서는 모두 가상 정보를 사용했습니다.

프랑스어 대사 선택: `J’ai mal à la gorge depuis deux jours.`
한국어 자막: `이틀 전부터 목이 아파요.`

### 01:55–02:20 원문 저장과 실제 번역
화면: 원문 저장 → AI 전송 안내 확인 → 동의 → Gemini 번역 → 한국어 결과.

나레이션: 원문을 먼저 보존하고, 동의한 뒤 Gemini로 한국어 번역을 요청합니다. 성명과 이메일, 선택한 병원 정보는 번역 요청에서 제외합니다. AI가 만든 결과는 바로 확정하지 않습니다.

### 02:20–02:50 대조·확인·의료진 화면
화면: 프랑스어 원문과 한국어 비교 → 필요한 표현 수정 → 사용자 확인 저장 → 의료진에게 보여주기.

나레이션: 원문과 번역을 대조하고 수정한 뒤 확인합니다. 이제 선택한 병원 이름과 주소, 한국어 증상, 시작 시점, 알레르기와 복용약이 하나의 준비표에 남습니다. 모리의 핵심은 이처럼 갈 곳을 찾는 과정과 전할 말을 준비하는 과정이 이어진다는 점입니다.

## 02:50–03:15 · 슬라이드 6 · 전달과 정보 보존

준비표는 의료진에게 화면으로 보여주거나 PDF로 만들 수 있습니다. 첫 장에는 주요 내용이, 별첨에는 원문과 상세 기록이 남습니다. 모르는 정보와 해당 없는 정보를 구분하고, 필요한 일상 기록만 포함합니다. 사용자 확인은 의료진의 검수를 의미하지 않으며, 이 문서는 환자가 작성한 방문 준비 자료입니다.

상단 PDF 저장·공유 버튼을 눌러 내려받은 파일을 직접 열어 보여준다. 기본 한 장 안에서 병원·증상·원문·번역을 보여준다. 길면 자동으로 다음 장에 이어지고 직접 선택한 과거 기록만 별첨된다. 촬영에서도 실제 파일을 열고, 문제가 나면 화면 표시로 전달하며 저장 성공으로 연출하지 않는다.
