# MORI 진료 준비 질문 근거 — 2026-11-08

공식 병원의 문진표를 채택하거나 검증받은 것이 아니다. 아래 공공기관 원문을 확인해 질문 주제를 선택하고, MORI가 질문·순서·다국어 안내를 작성했다. 기관의 제휴·승인 또는 의료적 타당성 검증을 뜻하지 않는다. 질문 1(증상)·2(시작 시점)는 기존 필수 입력이며 시작 시점은 모름을 허용한다. 알레르기와 약은 기존 없음/모름/내용있음 구분을 유지하고 나머지는 선택 입력이다. 캐릭터는 고정된 안내 그림이며 응답을 해석해 건강 상태를 바꾸지 않는다.

## 기존 선택 입력과 구별
기존 추가 정보(경과, 성명, 부위 그림, 0–10 통증 입력, 측정 체온)는 MORI의 보조 기록 필드다. 위 출처가 해당 점수 체계·의료용 설문을 검증한 것으로 표시하지 않는다. 자동 위험 분류·진단 점수 없음. 추가 질문 답변은 기존 composeVisitConcern으로 원문에 병합되고 같은 번역·원문 확인·PDF 경로를 사용한다. 빈 답을 '없음'으로 바꾸지 않는다. 외부 출처 링크에는 증상·사용자 정보를 첨부하지 않는다.
