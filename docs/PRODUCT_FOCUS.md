# MORI 제품 결정 — 2026-11-04

## 핵심 약속
한국어로 증상을 설명하기 어려운 외국인 거주자가 자기 언어로 방문 이유와 경과를 정리하고, 병원에서 보여줄 진료 준비표를 만든다.

## 왜 쓸 것인가 — 검증할 가설
지도는 기관 위치를, 번역기는 입력한 문장의 번역을 제공한다. 모리의 차별화 가설은 방문에 필요한 정보의 빠진 부분을 안내하고, 선택한 건강기록과 원문·번역을 함께 전달하는 것이다. 의료진의 실제 수용성, 번역기 대비 효과, 재사용 동기는 아직 검증되지 않았다. PDF 자체나 아바타를 경쟁 우위로 주장하지 않는다.

## 우선 사용자와 사용 순간
한국 병원 이용 경험이 적고 한국어 설명에 어려움을 느끼는 외국인 학생. 일반 진료를 준비하는 순간에 집중한다. 긴급 연락 경로는 기존대로 즉시 접근 가능하게 유지한다.

## 핵심 경로와 완료 조건
방문 이유 → 시작 시점 → 변화·악화/완화·질문(선택) → 복약/알레르기와 포함 기록 확인 → 원문 저장 → 번역 확인 → 의료진 표시/PDF.
1. 원문과 숫자를 손실 없이 저장한다.
2. 미응답을 없음/정상으로 추정하지 않는다.
3. AI 실패 시 원문 준비표가 유지된다.
4. 진료 준비표 첫 장에서 방문 이유·경과·약·알레르기를 찾을 수 있어야 한다. 상세 기록은 별첨으로 제공하는 것이 목표이며 현재 PDF는 길이에 따라 다중 페이지다.
5. 실제 휴대폰 저장과 타인 기기 접속을 확인한다.

## 이번 구현
방문 준비 화면에 증상 변화, 악화/완화 상황, 의료진에게 질문을 선택 입력으로 추가. 입력한 답만 한영 항목명과 함께 기존 symptoms 스냅샷에 포함하여 저장·기존 AI 번역·PDF 경로에서 유실되지 않도록 했다. 합계 2000자 초과는 잘라내지 않고 오류로 안내한다. 이름/정량 intake는 기존 AI 제외 정책을 유지한다. 추가 필드 답변은 증상 본문으로 AI 선택 시 전송된다. 자동 추론이나 진단은 추가하지 않았다.

## 이번 제출 범위
핵심: 진료 준비표, 실제 번역·대조, 병원 탐색, 실행 경로 검증.
보조: 아바타·기존 일상 기록·커뮤니티 유지.
보류: 워치 확장, 새로운 친구 기능, 종합 건강점수, 자동 질병 진단, 전면 Firebase 이전. 기존 서버 배포 가능성을 먼저 검증한다.

## 반증 가능한 검증
외국인 사용자 2명 이상에게 가상 사례를 주고 설명 없이 작성하도록 한다. 완료 시간·도움 요청·중도 포기를 기록한다. 일반 번역 방식과 모리 준비표의 사실 누락/추가/숫자 오류를 비교한다. 가능하면 의료진에게 방문 이유/경과/복약/알레르기 찾기와 불필요한 항목을 검토받는다. 완료율이나 시간 절감 수치를 측정 전 주장하지 않는다. 의료진이 읽지 않거나 입력 부담이 크면 정보량과 절차를 줄인다.
