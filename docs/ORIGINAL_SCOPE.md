## 2026-11-03 일반의료·한국전통의학·약국 분리
기본 카테고리는 한의원/한방병원을 제외한 일반의료 535곳(치과·보건기관 포함)이다. 한의원128·한방병원6은 한국 전통의학 탭134곳에만 표시한다. 의료 신체 그림 필터는 일반의료에만 적용하며 지도·거리 결과도 선택 카테고리와 일치한다.
원본 ZIP의 약국 CSV에서 포항237곳을 별도 pharmacies.json으로 추출했다. 원본 종별은 모두 약국이며 양약/한약 면허·개설자 구분 필드가 없다. 양약국/한약국 카테고리를 만들되 검증된 classificationEvidence가 있는 기관만 넣는다. 현재237곳은 모두 유형 미확인 별도 카테고리로 제공한다. 상호의 한약 문자열로 분류하지 않는다(편한약국/행복한약국 등 오분류 방지). 이는 한약국이 없다는 뜻이 아니라 구분 근거가 없다는 뜻이다. 정밀 분류는 지자체/공식 확인 근거를 확보한 뒤 추가한다.

검증: 서버22개·앱18개 테스트 통과, 코드 검사와 웹/iOS 빌드 성공. 아이폰 UI에서 Korean medicine 선택 시134건과 전통의학 표기, 유형 미확인 약국 선택 시237건을 확인했다. 양약국/한약국 확인 데이터가 아직 없다는 원본 제약은 남아 있다.


## 2026-11-04 제품 집중 및 방문 이유 입력

## 2026-11-04 진료 준비표 첫 장 구현
A4 첫 장에 방문 이유·경과, 시작 시점, 알레르기, 복약, 본인 입력 통증·체온을 배치했다. 확인된 번역만 첫 장에 사용하고 미확인 번역은 원문을 대체하지 않는다. 긴 항목은 발췌 안내와 함께 제한하고 전체 원문·번역·선택 기록은 다음 장부터 보존한다. 첫 장은 의미를 새로 생성한 AI 요약이 아니라 저장 내용의 발췌다. 웹 미리보기에도 동일한 요약 데이터를 먼저 표시한다.

## 2026-11-04 Google Maps와 방문 준비 연결

- Google Maps 키 미발급: 앱 안 지도는 SDK를 생성하지 않고 외부 Google 지도 버튼을 표시한다. iOS/Android/web 플랫폼별 키 설정 경로는 GOOGLE_MAPS_SETUP.md. 실제 지도 타일·인증·과금·실기기 위치는 미검증이다.

검증: Flutter analyze 이상 없음, 앱 테스트22개 통과(키가 없을 때 네이티브 지도 생성 없이 외부 지도 버튼 동작 포함), 웹 빌드 및 iOS 시뮬레이터 빌드 성공. 브라우저에서 첫 일반 진료→535개 기본 목록, 병원 선택→로그인 안내에 병원명·주소 유지, 실제 Google 길찾기 URL의 해당 병원 좌표 전달을 확인했다. Mac 잠금으로 이번 아이폰 UI 직접 검사는 미완료. Android 빌드·실제 Google 지도 인증은 미검증.
