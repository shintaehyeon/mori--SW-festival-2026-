# Gemini 서버 설정

server/.env.example을 참고하여 무시되는 server/.env에 AI_PROVIDER=gemini, GEMINI_API_KEY=<로컬에서만 입력>, GEMINI_MODEL=gemini-3.5-flash-lite를 설정한다. AI Gateway 키는 이 모드에서 사용하지 않는다. 키를 앱·Git·채팅에 넣지 않는다. 서버를 재시작하고 /api/health의 aiConfigured를 확인한다. 이는 설정 존재 확인일 뿐 키 유효성/모델 접근/품질 검증이 아니다.

가상 사례로 원문 카드 저장 → AI 번역 → 원문/번역 대조 → 사용자 확인을 수행한다. 약명·숫자·부정·시간·없음/모름을 직접 점검한다. 네트워크 실패/차단/불완전 응답 시 원문을 유지한다. 현재 번역 출력은 한국어이며 전체 앱 다국어 번역이 아니다.


## 2026-11-08 실제 키 연결
사용자 승인으로 Capston 무료 등급 프로젝트에 MORI demo 키를 발급하고 server/.env에만 저장했다. 파일은0600이며 Git 제외, 패키징에서도 .env 제외. 키 값·프로젝트 인증 자격은 문서에 기록하지 않는다. 결제 설정은 변경하지 않았다.
모델 목록 인증200 확인. 기존 gemini-2.5-flash는 신규 사용자에404, gemini-3.8-flash는 타임아웃/일부 실패를 관찰했다. gemini-3.1-flash-lite는 단문3건에 성공했으나 일지 포함 요청에서30초 타임아웃을 관찰했다. 최종적으로 단문 및 일지 포함 요청이 통과한 gemini-3.5-flash-lite를 사용한다.
가상 영어/프랑스어/일본어 및 일지 포함 영어4건 모두 번역 성공(최종 재검사 약1.1~1.6초). 원문 숫자2/3/500, 호흡곤란 없음/구토 없음/발열 없음, 알레르기·복약의 없음/모름, 원문 약명 보존을 확인. 이4건은 의료 번역 품질 인증이나 전체 언어 검증이 아니다.
재현: server 폴더에서 `npm run qa:gemini`. 스크립트는 고정 가상 사례만 보내며 실제 사용자 DB를 읽지 않는다. 결과는 output/qa-gemini/live-translation-20261108.json에 저장된다. 무료 API 실험에는 가상 데이터만 사용하고 실제 개인정보·건강정보를 보내는 서비스 적용은 별도 조건 검토가 필요하다.

앱 E2E 추가 확인: 가상 카드에서 전송 동의→실제 Gemini 번역→원문 비교→어색한 표현 직접 수정→사용자 확인 저장→한국어 준비표 표시까지 확인했다. 확인된 번역의 재번역 버튼 비활성 및 원문/수치 보존을 확인. 사용자 확인은 의료진 검수를 의미하지 않는다. PDF 실제 다운로드는 이번 추가 검사에서 수행하지 않았다.
