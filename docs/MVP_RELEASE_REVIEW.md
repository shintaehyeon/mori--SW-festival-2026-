# MORI 제출 전 PM/QA 최종 개선 판정 — 2026-11-08

## 제품 결정

**한동대 외국인 유학생이 아플 때, 갈 병원을 찾고 한국어로 전할 말을 준비한다.**

Caroline은 프랑스인 한동대 유학생이자 문제를 실제 겪은 팀원이다(사용자 제공). 신태현은 개발, Caroline은 문제 정의·최종 사용성 테스트·영상 발표를 담당한다. 실제 문제에서 출발했다는 사실과 사용성·의료진 효과를 평가했다는 주장은 구분한다.

제출 MVP의 와우 장면은 기능 목록이 아니다. **프랑스어로 쓴 방문 이유가 선택한 병원명·주소와 함께 한국어 준비표가 되고, 다시 열거나 PDF로 꺼내 보여지는 순간**이다.

## 기존 핵심 개선 유지

- 공식기관 ID 검증 → 기관명/주소 스냅샷 → 재조회·의료진 화면·PDF 보존.
- 증상/시작 시점 우선, 상세 경과·수치는 선택 입력.
- 준비표 경로 가입 뒤 불필요한 기본정보 입력 우회 제거.
- 사용자 확인 후 AI 재번역과 동시 요청 덮어쓰기 차단.
- 친구/워치/접속 집계 진입 제외. 원래 기획의 건강기록·경험 공유는 보조로 유지.
- 로그인 전 119·112와 한동대 학생 지원 연락망 제공. 학교의 공식 앱이나 24시간 응답 서비스로 표현하지 않는다.

## 제출 전 선택과 집중

1. **오늘 수정 대상:** 저장·번역·재조회·표시의 실패, 증상/기관 불일치, 다음 행동을 막는 문구. 발생하면 재현→수정→해당 경로 재검사.
2. **Caroline 최종 테스트:** `CAROLINE_FINAL_TEST.md`의 15분 과제. 개발자가 버튼을 먼저 알려주지 않고 멈춘 지점·개입을 기록한다. 이미 익숙한 공동 제작자이므로 독립 사용자 검증으로 확대하지 않는다.
3. **시연 중심:** 기관 선택 → 가상 프랑스어 증상 → 실제 Gemini → 원문 대조 확인 → 병원명이 담긴 준비표 → PDF 파일 열기. 튜토리얼은 이 실제 동작을 대신하지 않는다.
4. **후속 작업:** 워치·이상 감지·음성 통역·전국 확대·새 수익 모델 구현. 마감 직전에는 추가하지 않는다.

## 검증과 남은 의사결정

앱 자동 테스트 45개, 서버 28개. 정적 분석·웹 빌드 및 iOS 시뮬레이터 빌드 결과는 QA 기록에 보존한다. 프랑스어 실제 Gemini 성공 기록은 앞선 검증에서 확보했고, 이번에는 그 저장 카드를 재조회해 실제 웹 PDF 다운로드까지 이어 검증했다.

남은 것은 ‘포기한 개발 항목’이 아니라 성격이 다른 검증이다. 실물 GPS, 실제 기기의 전화 화면 연결, Caroline 사용성 결과, 독립 사용자·의료진 평가를 자동 테스트로 대체하지 않는다. 실제 긴급번호 발신은 하지 않는다. 현재 지도 키 없는 환경은 외부 Google 지도 경로로 시연한다. 무료 Gemini에는 가상 자료만 사용한다.

**판정: 제출용 비응급 방문 준비 시제품으로 범위를 고정한다. 알려진 핵심 저장·내보내기 문제를 수정했고 실제 웹 다운로드를 확인했다. ‘100% 효과 입증’ 대신 재현 가능한 동작과 테스트 결과를 제출한다.** 출품 PDF/ZIP 준비, 영상 완성, 접수 완료는 각각 별도로 확인한다.


## 최종 정보 구조 개편 — 기본 한 장
앞의 4쪽 다운로드 검증은 개편 전 기록이다. 현재 버전은 기본 한 장이며, 입력하지 않은 수치와 빈 메모 페이지를 제거했다. 한국어·원문·확인 상태·알레르기·복용약·선택 기관은 보존한다. 긴 내용은 잘라내지 않고 이어지며 직접 첨부한 과거 기록만 별첨한다. 과거 기록 선택은 기본 접힘, 기록이 없으면 단계 자체가 없다. 짧은 원문/미확인/확인 완료 PDF 3종 모두 1쪽, 장문 기록은 5쪽으로 원문 보존 확인. 증거: screenshots/mori-compact-pdf-20261108.png.


## 2026-11-08 병원 카드·게스트 여정 개선
병원명/주소/의사 수/핵심 방문 준비 CTA를 분리하고 상세 진료과는 접었다. Google 외부 길찾기와 전화만 보조 행동으로 남겼다. 게스트로 원문 저장·실제 Gemini 번역·확인 저장·PDF까지 연결했다. 게스트 세션 24시간, 만료 데이터는 다음 요청 시 삭제. 계정 전환 전 PDF 저장 안내. 후기 열람·작성은 계정 로그인 필요; 작성 형식 예시는 실제 후기가 아니다. Google 공식 로그인 플러그인과 서버 토큰 검증을 준비했으나 OAuth 클라이언트 미설정으로 버튼은 숨김. Firebase 미사용, Node.js/SQLite 유지.
