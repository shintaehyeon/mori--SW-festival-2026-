# MORI 제출 전 PM/QA 판정 — 2026-11-08

## 판단
문제 정의와 핵심 구현은 연결돼 있다. 그러나 실제 외국인·의료진 평가가 없어 효과를 입증한 제품이라고 말할 수 없다. 제출용 시제품으로는 포항 비응급 방문 준비에 집중한다.

한 문장: 한국에서 아픈 외국인이 진료과와 병원을 찾고, 자신의 증상을 한국어로 전달하도록 돕는다.

## 가장 큰 문제와 대응
- 병원 선택이 화면에만 남던 문제: 공식기관 ID를 검증하고 병원명/주소를 카드 스냅샷에 저장, 재조회·의료진 표시·PDF에서 보존.
- 입력 부담: 증상/시작 시점 우선, 상세 경과/수치 선택 입력을 접음.
- 주목적 분산: 친구/워치/접속 집계 진입 제거, 작은 모리와 기록 기능은 유지. 최초 커뮤니티는 경험 공유로 유지.
- 준비 중 가입 후 다른 정보 입력으로 우회: 준비표 경로에서 자동 기본정보 설정 생략.
- AI가 사용자 확인 내용을 덮어쓸 위험: 확인 후 재번역 차단 및 서버 동시 요청 보호 회귀 검사.
- 혼동되는 문서: README를 현재 구현/미검증/후속 작업 기준으로 다시 작성.

## 출시 판단의 한계
- 자동 진료과 판단·진단·예약·실시간 통역이 아니다.
- 지도 키/실물 GPS와 최신 웹 PDF 다운로드 전체 경로는 별도 확인 필요.
- 실제 긴급전화 발신은 검사하지 않는다. 실폰 전화 화면 연결까지만 확인할 것.
- 무료 Gemini는 가상 자료 시연 전용. 실사용 조건 검토 전 실제 건강정보로 확장하지 않는다.
- 튜토리얼은 사용법 설명용이다. 실제 모델 호출 성공을 대신하는 증거가 아니다.
- 출품 접수/연구보고서/발표자료/영상의 완료 여부는 코드 QA와 별개다.

## 시연 합격 기준
프랑스어 가상 사례로 병원 선택 → 증상 입력 → 번역/대조 확인 → 병원명이 포함된 준비표를 보여준다. 사용자가 어디서 멈추는지 숨기지 않고 기록한다. 시간을 절감했다는 수치를 측정 없이 쓰지 않는다.

## 최종 검증 기록
서버28개 테스트 통과: 공식 병원 ID 검증·카드 재조회 시 이름/주소 유지·위조 병원명 무시·알 수 없는 ID 거부·과거 병원 미선택 카드 호환 포함. PDF 가상 샘플을 생성·렌더링하여 병원명/주소·예약 아님·첫 장 배치 확인. 6개 언어 필수 리소스 검사에서 누락된 신규 문구를 발견해 보완했다.


## 최종 제출용 MVP 검증
Flutter analyze 통과, 앱 전체38개 테스트 및 서버28개 테스트 통과. 웹 빌드 및 iOS 시뮬레이터 빌드 성공. 프랑스어 웹에서 병원 검색→강이비인후과 선택→가상 프랑스어 증상·시작 입력→원문 저장→동의 후 실제 Gemini 번역→원문 대조 확인 저장→병원명/주소와 한국어 증상이 담긴 의료진 준비표 표시를 확인했다. 가상 QA DB에서도 destination/confirmedAt/mode=ai/프랑스어 원문 보존 확인. PDF 가상 예시를 생성·렌더링해 첫 장 병원 정보와 본문이 잘리지 않음을 확인. 웹 파일 다운로드·실물 GPS·의료진 유용성 검증은 여전히 별도다. 증거: screenshots/mori-final-mvp-fr-20261108.png, screenshots/mori-final-pdf-20261108.png.
